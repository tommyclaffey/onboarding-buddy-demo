# Onboarding Buddy: portfolio demo

Static build of Onboarding Buddy for Tommy Claffey's portfolio. It opens signed in as Hana, a new hire at Brightside (a made-up company), with a short guided walkthrough. Everything runs in the browser; each visit starts from a fresh copy of the demo data.

Live: https://tommyclaffey.github.io/onboarding-buddy-demo/
